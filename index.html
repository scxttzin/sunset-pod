      Como as alterações são salvas

      Tudo o que você edita aqui fica guardado neste navegador (localStorage). Isso deixa o painel instantâneo e sem custo de servidor — mas as mudanças ainda não aparecem para os clientes.

      Como publicar para todo mundo

      1. Clique em Exportar dados — baixa o arquivo seed.js.
      2. Substitua o arquivo data/seed.js do site por esse arquivo.
      3. Suba a pasta para a hospedagem (Netlify, Vercel, GitHub Pages…).

      O campo version é incrementado a cada exportação: quando o visitante abre o site com uma versão maior que a guardada, os dados novos entram automaticamente. Versão atual destes dados: —.
